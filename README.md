# UIツールキット（TurboWarp カスタム拡張機能）

ステージの上に **ボタン・入力欄・スライダー・タブ・ウィンドウなどのUI部品**、**通知（トースト）**、**ダイアログ** を作れる TurboWarp 用の拡張機能です。
Scratch の変数との連動、アニメーション、ショートカットキー、レイアウトの保存と復元にも対応しています。

- 全ブロック **日本語**
- ライト / ダークテーマ、アクセント色、角丸、フォントを自由に変更可能
- UI はステージ内に重ねて表示されるので、**全画面表示でも一緒に拡大**されます
- ファイルは `ui-toolkit.js` 1つだけ（外部ライブラリ・外部通信なし）

## 導入方法

1. [TurboWarp](https://turbowarp.org/editor) のエディターを開きます。
2. 左下の **「拡張機能を追加」** → **「カスタム拡張機能」** を選びます。
3. **「ファイル」** タブで `ui-toolkit.js` を選びます。
4. **「サンドボックス外で実行」にチェックを入れて** 読み込みます。

> **重要:** この拡張機能は画面（DOM）を直接操作するため、サンドボックス外（Unsandboxed）での実行が必須です。チェックを入れずに読み込むとエラーになります。
> 本家 Scratch はサンドボックス外のカスタム拡張機能に対応していないため、**TurboWarp 専用**です。

プロジェクトを「HTMLにパッケージ化」して配布する場合も、拡張機能はプロジェクトに同梱されます。

## クイックスタート

ボタンを押したら通知を出す、いちばん小さな例です。

```
緑の旗が押されたとき
  [ボタン] [start] を作成 テキスト [スタート] x [0] y [0]

[start] の [クリック] が起きたとき
  通知 [スタートしました！] を表示 種類 [成功] 秒数 [3]
```

もっと手軽に「押されるまで待つ」書き方もできます。

```
緑の旗が押されたとき
  [ボタン] [start] を作成 テキスト [スタート] x [0] y [0]
  [start] の [クリック] を待つ（最大 [0] 秒・0で無制限）
  [start] を削除
  （ゲーム開始の処理）
```

## 基本の考え方

### ID で部品を管理する

部品はすべて **ID（名前）** で管理します。作成時に付けた ID を、以後のブロックで指定します。
同じ ID で作成し直すと、古い部品は置き換えられます。

### 座標とアンカー

座標は Scratch と同じ向き（右が +x、上が +y）です。

| アンカー | x, y の意味 |
| --- | --- |
| **中央**（初期値） | ステージ中央が原点。**部品の中心**がその座標に来ます |
| 左上・上・右上・左・右・左下・下・右下 | その位置の辺から「余白 + x, y」だけずれた位置に固定 |

HUD（スコアなど）や画面端のボタンは、アンカーを使うと座標計算が要りません。

```
[ラベル] [score] を作成 テキスト [スコア: 0] x [0] y [0]
[score] を [左上] に固定 余白 [16] px
```

### 親子関係（自動レイアウト）

**パネル（縦並び / 横並び）** と **ウィンドウ** は入れ物になります。
`[ID] を [PARENT] の中に入れる` で部品を入れると、**座標指定は不要で自動的に並びます**（親に入れた部品の x, y・アンカーは無視されます）。
入れ物を削除すると、中の部品も一緒に削除されます。

### テキスト内の改行

通知・ダイアログ・部品のテキストに **`\n`**（バックスラッシュ + n）と書くと改行になります。

### 停止ボタンで自動的に消える

初期設定では、**停止ボタンを押すとすべてのUI（部品・通知・ダイアログ・ローディング）が消えます。**
消したくない場合は `停止ボタンでUIを消す: [オフ]` を実行してください。

## UI部品の一覧

`[TYPE] [ID] を作成 テキスト [TEXT]` で作成できる部品です。部品の種類によって **「テキスト」の意味** が変わります。

| 種類 | テキストの意味 | 「値」の意味 | 主なイベント |
| --- | --- | --- | --- |
| ボタン | ボタンの文字 | （ボタンの文字） | クリック |
| ラベル | 表示する文字 | （表示する文字） | クリック |
| 入力欄 | 入力されている文字 | 入力されている文字 | 入力中・値の確定・Enterキー |
| 複数行入力欄 | 入力されている文字 | 入力されている文字 | 入力中・値の確定・Enterキー（Ctrl+Enter） |
| 数値入力欄 | 入力されている数 | 数値 | 入力中・値の確定・Enterキー |
| 色選択 | 色（例: `#ff0000`） | 色（`#rrggbb`） | 入力中・値の確定 |
| チェックボックス | 横に表示する文字 | `true` / `false` | 値の確定 |
| スイッチ | 横に表示する文字 | `true` / `false` | 値の確定 |
| スライダー | 上に表示する文字 | 数値 | 入力中・値の確定 |
| ドロップダウン | **選択肢の一覧** | 選択中の選択肢 | 値の確定 |
| リスト | **選択肢の一覧** | 選択中の選択肢 | 値の確定・ダブルクリック |
| ラジオボタン | **選択肢の一覧** | 選択中の選択肢 | 値の確定 |
| タブ | **選択肢の一覧** | 選択中のタブ | 値の確定 |
| プログレスバー | バー上の文字（`{p}` は進捗率%に置換） | 現在値 | クリック |
| 画像 | （使いません） | 画像のURL | クリック |
| パネル（縦並び / 横並び） | （使いません） | （なし） | クリック |
| ウィンドウ | タイトル | （なし） | 閉じる |

**選択肢の書き方**は次のどれでも使えます。

- カンマ区切り: `りんご,みかん,ぶどう`
- 改行区切り: `りんご\nみかん\nぶどう`
- JSON配列: `["りんご","みかん","ぶどう"]`（項目にカンマを含めたいとき）

**補足**

- **ウィンドウ** はタイトルバーをドラッグして動かせます。✕ で非表示になり、「閉じる」イベントが発生します。
- **タブ** は選択肢の最初の項目が最初から選ばれます。タブを切り替えて、パネルの表示 / 非表示を切り替える使い方が便利です。
- **画像** のURLは、TurboWarp の許可確認を通ったもの（`data:` URL など）だけ表示されます。

## ブロックリファレンス

### テーマ

| ブロック | 説明 |
| --- | --- |
| `テーマを [ライト/ダーク/自動] にする` | 配色を切り替えます。自動はOSの設定に追従します |
| `アクセント色を [色] にする` | ボタンやスライダーなどの強調色 |
| `カラープリセット [プリセット] を適用` | ブルー・インディゴ・パープル・ピンク・レッド・オレンジ・イエロー・グリーン・ティール・グレー |
| `テーマの [項目] を [値] にする（空欄で初期値）` | アクセント色・背景色・文字色・文字サイズ(px)・角丸(px)・フォント |
| `テーマを初期状態に戻す` | すべてのテーマ設定をリセット |
| `停止ボタンでUIを消す: [オン/オフ]` | 停止時の自動削除の切り替え |

### 通知（トースト）

| ブロック | 説明 |
| --- | --- |
| `通知 [テキスト] を表示 種類 [種類] 秒数 [秒]（0で消えない）` | 情報・成功・警告・エラーの4種類。クリックでも消せます。同時に最大6件 |
| `通知の表示位置を [位置] にする` | 左上・上中央・右上・左下・下中央・右下 |
| `すべての通知を消す` | |

### ダイアログ

ダイアログは **結果が出るまでスクリプトが待機** します。複数のダイアログを同時に呼び出した場合は、順番に1つずつ表示されます。
Enter で決定、Esc でキャンセル、Tab でフォーカス移動ができます。

| ブロック | 説明 |
| --- | --- |
| `アラート タイトル [ ] 本文 [ ] を表示して待つ` | OK だけのお知らせ |
| `確認 タイトル [ ] 本文 [ ]`（真偽値） | OK なら true、キャンセルなら false |
| `入力ダイアログ タイトル [ ] 本文 [ ] 初期値 [ ]` | 入力した文字を返す。キャンセル時は空 |
| `選択ダイアログ タイトル [ ] 本文 [ ] 選択肢 [ ]` | 選んだ項目を返す。キャンセル時は空 |
| `直前のダイアログはキャンセルされた` | 入力 / 選択 / 確認の結果判定用 |
| `直前の選択ダイアログの番号` | 選んだ項目の番号（1から。キャンセル時は 0） |
| `ダイアログのボタン名を OK [ ] キャンセル [ ] にする` | ボタンの文言を変更 |
| `ローディング [表示/非表示] テキスト [ ]` | 回転アイコン付きの待機画面。表示中はステージを操作できません |

### UI部品の作成と削除

| ブロック | 説明 |
| --- | --- |
| `[種類] [ID] を作成 テキスト [ ] x [ ] y [ ]` | 部品を作成 |
| `[ID] を削除` | 入れ物の場合は中身も削除 |
| `すべてのUI部品を削除` | 通知・ダイアログは対象外 |
| `[ID] を [親ID] の中に入れる（空欄で解除）` | パネル / ウィンドウに入れる。解除するとステージ直下に戻る |

### 内容・見た目の設定

| ブロック | 説明 |
| --- | --- |
| `[ID] のテキストを [ ] にする` | 部品の種類ごとの意味は [UI部品の一覧](#ui部品の一覧) 参照 |
| `[ID] の値を [ ] にする` | 値を設定（イベントは発生しません） |
| `[ID] の選択肢を [ ] にする` | ドロップダウン / リスト / ラジオ / タブ。選択中の項目は、残っていれば維持されます |
| `[ID] の範囲を 最小 [ ] 最大 [ ] 刻み [ ] にする` | スライダー・数値入力欄・プログレスバー（プログレスは刻み不要） |
| `[ID] を x [ ] y [ ] に移動` / `だけ動かす` | アンカーからの位置 |
| `[ID] を [アンカー] に固定 余白 [ ] px` | 画面端への固定 |
| `[ID] のサイズを 幅 [ ] 高さ [ ] にする（0で自動）` | |
| `[ID] の [項目] を [値] にする` | 下表の見た目・動作の設定。空欄で初期値に戻ります |
| `[ID] にCSS [ ] を追加` | 上級者向け。例: `font-weight:bold;letter-spacing:2px` |

| `[ID] に [アニメーション] アニメーション 時間 [秒] 秒` | 待たずに次へ進む |
| `[ID] に [アニメーション] アニメーションをつけて待つ 時間 [秒] 秒` | 終わるまで待つ |

**`[ID] の [項目] を [値] にする` で設定できる項目**

| 項目 | 値の例 | 対象 |
| --- | --- | --- |
| 文字色 / 背景色 / 枠線色 | `#ff0000`, `red` | すべて |

| ツールチップ | `クリックで開始` | すべて（スクリーンリーダー用の名前にもなります） |
| プレースホルダー | `名前を入力` | 入力欄・複数行入力欄・数値入力欄 |
| 入力タイプ | `password` / `email` / `tel` / `url` / `search` / `text` | 入力欄 |
| 最大文字数 | `20` | 入力欄・複数行入力欄 |
| 内側の間隔(px) | `12` | パネル・ウィンドウ・ラジオ・タブ |
| 並び方 | `start` / `center` / `end` / `between` | パネル・ウィンドウ |

| ブロック | 説明 |
| --- | --- |

## イベントの扱い方

イベントは2通りの書き方があります。

**ハット（〜が起きたとき）** … 常に待ち受けるスクリプト。複数の部品を独立して扱えます。

```
[start] の [クリック] が起きたとき
  ...
```

**待機（〜を待つ）** … 1本のスクリプトの中で順番に進めたいとき。メニュー画面やチュートリアルに向いています。

```
[ボタン] [next] を作成 ...
[next] の [クリック] を待つ（最大 [0] 秒・0で無制限）
```

**全部品をまとめて処理する**書き方:

```
いずれかのUI部品が操作されたとき
  もし <(最後に操作されたUIのID) = [vol]> なら
    音量を (最後に操作されたUIの値) にする
```

**イベントの種類についての補足**

- 「値の確定」は入力欄ではフォーカスが外れたときや Enter のとき、スライダーでは操作を終えたとき、チェックボックス・ドロップダウン・タブ等では選択したときに発生します。
- 「入力中」はスライダーを動かしている間や、文字を打つたびに発生します。
- **「値を〜にする」ブロックで値を変えたときは、イベントは発生しません。**
- 「マウスが乗った」「フォーカス取得」「フォーカス喪失」は、`最後に操作されたUI〜` や `いずれかのUI部品が操作されたとき` には影響しません（クリックなどの操作の結果が上書きされないようにするためです）。

## 変数との連動

`[ID] を変数 [変数] と連動させる` を使うと、**Scratch の変数と UI の値が自動で同期**されます。ブロックを使った受け渡しが不要になります。

| 部品 | 動作 |
| --- | --- |
| スライダー・入力欄・チェックボックス・ドロップダウン・タブなど | **双方向**。操作すると変数が変わり、変数が変わると表示も変わります |
| ラベル・ボタン・ウィンドウ | **変数 → テキスト**。スコア表示などに使えます |
| プログレスバー | 変数 → 進捗 |

```
変数 [score] を [0] にする
[ラベル] [scoreLabel] を作成 テキスト [] x [0] y [0]
[scoreLabel] を [左上] に固定 余白 [16] px
[scoreLabel] を変数 [score] と連動させる
（以後、score を増やすだけで表示が更新される）
```

- 連動を開始した時点では **変数の値が UI に反映**されます（UIの初期値で変数を上書きしません）。
- 対象は **「すべてのスプライト用」の変数** です（「このスプライトのみ」の変数は選べません）。
- 変数の変更は毎フレーム確認されるため、反映までの遅れはほとんどありません。

## ショートカットキー

`[ID] にショートカットキー [キー] を割り当てる` で、キー操作でその部品の「クリック」を実行できます。ボタンなら本当にクリックされたのと同じ動作になります。

| 書き方の例 | キー |
| --- | --- |
| `s` | S |
| `ctrl+s` | Ctrl + S（Mac の Cmd も同じ扱い） |
| `shift+enter` | Shift + Enter |
| `escape` / `esc` | Esc |
| `space` | スペース |
| `arrowup` / `up` | ↑（`down` `left` `right` も同様） |
| `f5` | F5 |

- 大文字小文字は区別しません。修飾キーは `ctrl` `alt` `shift` が使えます。
- 非表示・無効の部品や、**入力欄・ダイアログの操作中は反応しません**（文字入力の邪魔をしないため）。
- 同じキーを複数の部品に割り当てた場合は、最後の割り当てが有効です。

## アニメーション

| 名前 | 動き |
| --- | --- |
| フェードイン | 透明から表示（非表示の部品は自動で表示） |
| フェードアウト（終了後に非表示） | 透明になって、終わると非表示 |
| ポップ（拡大しながら出現） | 小さい状態から少し弾んで表示 |
| 下 / 上からスライドイン | 24px 動きながら表示 |
| バウンス | 上下に弾む |
| シェイク | 左右に揺れる（入力ミスの表現など） |
| パルス | 一瞬ふくらむ（注目させる） |

OS の「視覚効果を減らす（Reduce motion）」設定がオンの場合、アニメーションは省略されます。
`〜をつけて待つ` を使うと、アニメーションを順番に実行できます。

```
[window] を [非表示]
[window] に [ポップ] アニメーションをつけて待つ 時間 [0.3] 秒
[ok] に [パルス] アニメーション 時間 [0.4] 秒
```

## テーマとスタイル

- **配色**は背景色と文字色から、面の色・枠線の色が自動で決まります。そのため、`背景色` と `文字色` を変えるだけで、全体の見た目がまとまります。
- 部品ごとに見た目を変えたいときは、`[ID] の [項目] を [値] にする`（特に **アクセント色**）が便利です。
  例: 削除ボタンだけ赤くする → `[delete] の [アクセント色] を [#e5484d] にする`
- アクセント色に合わせて、ボタン上の文字色（白 / 黒）は自動で見やすい方になります。
- テーマはいつでも切り替えられ、表示中の部品にもすぐ反映されます。

## レイアウトの保存と復元

| ブロック | 説明 |
| --- | --- |
| `UIレイアウトをJSONで書き出す` | 現在の全部品（種類・位置・アンカー・値・選択肢・スタイル・親子関係・表示状態・変数連動・ショートカット）をJSON文字列にします |
| `UIレイアウトをJSON [ ] から復元` | **既存の部品をすべて削除**してから、JSONの内容で作り直します |

変数やリスト、ファイルに保存しておけば、画面の切り替え（タイトル画面 → 設定画面など）や、ユーザーのレイアウト保存に使えます。
不正なJSONを渡した場合は、何も変更されません。

### ログインフォーム

```
緑の旗が押されたとき
  [ウィンドウ] [login] を作成 テキスト [ログイン] x [0] y [0]
  [入力欄] [user] を作成 テキスト [] x [0] y [0]
  [user] の [プレースホルダー] を [ユーザー名] にする
  [入力欄] [pass] を作成 テキスト [] x [0] y [0]
  [pass] の [入力タイプ] を [password] にする
  [ボタン] [send] を作成 テキスト [ログイン] x [0] y [0]
  [user] を [login] の中に入れる
  [pass] を [login] の中に入れる
  [send] を [login] の中に入れる
  [send] にショートカットキー [enter] を割り当てる
  [login] に [ポップ] アニメーション 時間 [0.3] 秒

[send] の [クリック] が起きたとき
  もし <(user の値) = []> なら
    [login] に [シェイク] アニメーション 時間 [0.4] 秒
    通知 [ユーザー名を入力してください] を表示 種類 [警告] 秒数 [3]
  でなければ
    通知 [ようこそ、(user の値) さん] を表示 種類 [成功] 秒数 [3]
    [login] を削除
```

## 注意点と制限

- **TurboWarp 専用**で、**サンドボックス外での実行が必須**です。信頼できるプロジェクトでのみ使ってください。
- UI は **ステージの内側にだけ**表示されます。ステージの外（エディターの余白など）には出せません。
- ブロックの表記は **日本語のみ**です。
- **安全面の配慮**として、`CSSを追加` や保存データ内の CSS に含まれる `url(...)` は無効化されます。画像は TurboWarp の許可確認（`Scratch.canFetch`）を通った URL だけ読み込まれます。
- ID に同じ名前を使うと上書きされます。ウィンドウやパネルを作り直す場合、中の部品は削除されるため、作り直してから入れ直してください。
- 無効にした部品（`[ID] を 無効にする`）は、マウスもキーボードも受け付けません。
- 動作確認の状況: ブロック定義とすべての機能（部品の作成・設定・イベント・変数連動・ショートカット・保存復元・ダイアログなど）は、擬似的なブラウザ環境で自動テストしています。**実際の TurboWarp 上での見た目の確認は、お使いの環境で行ってください。**

## トラブルシューティング

| 症状 | 対処 |
| --- | --- |
| 読み込み時に「サンドボックス外で実行」のエラーが出る | 読み込み時に **「サンドボックス外で実行」にチェック**を入れてください |
| UI が何も表示されない | `[種類] [ID] を作成` を実行したか、`すべてのUI部品を削除` や停止ボタンで消えていないか確認してください |
| 位置が思った場所にならない | アンカーが「中央」以外だと、x, y は固定位置からのずれになります。親に入れた部品は座標が無視されます |
| 停止ボタンを押すと UI が消えてしまう | `停止ボタンでUIを消す: [オフ]` にしてください |
| ハットブロックが動かない | ID と、メニューのイベント名が一致しているか確認してください（ID は大文字小文字を区別します） |
| 入力欄でスペースキーを押すとスプライトが反応する | 通常は入力欄の中のキー操作は Scratch に伝わりません。入力欄でない場所にフォーカスがないか確認してください |
| 変数が選択肢に出ない | 「すべてのスプライト用」の変数だけが対象です。変数を作成してから、ブロックのメニューを開き直してください |
| 画像が表示されない | 許可されていない URL は読み込まれません。`data:` URL か、TurboWarp が許可する URL を使ってください |
| 色選択・タブなどで見た目が崩れる | ブラウザが古い可能性があります。最新の Chrome / Edge / Firefox / Safari をお使いください |
